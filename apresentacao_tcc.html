Servidor de Impressão Automatizada

Revitalização de impressoras legadas

Conectividade, mobilidade e pagamento via Pix


Autor: Lucas Bastos Rezende

Use as setas do teclado para avançar.

O problema

  • Impressoras antigas ainda funcionam, mas muitas são descartadas por falta de conectividade.
  • O envio por pendrive, e-mail ou aplicativo de mensagem gera atraso e risco de segurança.
  • A cobrança manual pode causar erro de valor, fila de atendimento e perda de controle.

A solução proposta

  • Criar um servidor web local para receber arquivos pelo navegador.
  • Permitir que o usuário configure páginas, cópias, cor e orientação antes de imprimir.
  • Liberar a impressão somente depois do pagamento via Pix ou da confirmação manual.

Objetivos do projeto

Modernizar o uso de impressoras comuns com baixo custo.

  • Facilitar a impressão em papelarias, bibliotecas e pequenos comércios.
  • Diminuir o descarte de equipamentos ainda funcionais.
  • Automatizar cobrança, envio e exclusão segura do arquivo.

Arquitetura do sistema

  • Interface: HTML, CSS e JavaScript no navegador.
  • Servidor: Python com Flask controlando rotas e regras de negócio.
  • Impressão: SumatraPDF e Pillow no Windows.
  • Pagamento: Mercado Pago para Pix dinâmico e QR estático como alternativa.
Python Flask JavaScript Pix

Principais funcionalidades

  • Envio de arquivos por clique ou arrastar e soltar.
  • Pré-visualização interativa de PDFs e imagens.
  • Seleção de páginas e quantidade de cópias por página.
  • Modo de demonstração para apresentar o fluxo sem cobrança real.

Pagamento Pix

  • Pix dinâmico: cobrança criada pelo Mercado Pago, com verificação automática.
  • Pix estático: QR Code gerado localmente, com confirmação manual.
  • Regra principal: a impressão só acontece depois da liberação do pagamento.

Trabalhos futuros

  • Criar painel administrativo com histórico de impressões.
  • Adicionar fila para múltiplas impressoras.
  • Usar webhook do Mercado Pago em vez de consulta por intervalo.
  • Preparar uma versão para Linux usando CUPS.

Conclusão

  • O projeto prova que uma impressora comum pode ganhar recursos modernos com software.
  • A solução reduz trabalho manual e organiza o fluxo de impressão em comércios locais.
  • O sistema une reaproveitamento de hardware, interface web e pagamento digital.
